# MINDUSAGE.md

# Core Philosophy

Babymomo must NEVER feel like:
- a clone
- a wrapper
- a developer playground

It should feel like:
- a living AI companion
- an AI-native mobile ecosystem
- a consumer-first intelligence layer

---

# UX Mindset

Hide complexity.

Never expose:
- quantization jargon
- GPU settings
- runtime internals

Instead expose:
- Fast
- Balanced
- High Quality

---

# Design Philosophy

The UI should feel:
- soft
- cinematic
- tactile
- emotionally warm
- futuristic

Avoid:
- terminal aesthetics
- enterprise dashboards
- cluttered interfaces

---

# AI Coding Agent Rules

## ALWAYS
- modularize
- abstract runtimes
- separate UI from inference
- optimize for mobile
- prioritize emotional UX

## NEVER
- hardcode providers
- tightly couple systems
- clone ChatGPT layouts
- expose raw technical systems

---

# Babymomo Identity

Babymomo is:
- mascot-driven
- emotionally expressive

- playful but premium

The mascot should feel:
- alive
- subtle
- warm
- intelligent
